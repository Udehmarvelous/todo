# 📝 Python To-Do List

My first new project while learning Python! 🚀

This is a simple **command-line To-Do List application** built with Python.  
The project allows users to add, view, edit, and complete their todos directly from the terminal.

## 🎯 About The Project

I created this project as one of my first practical projects while learning Python.

The goal was to take the Python concepts I have been learning and use them together to build something that actually works.

Through this project, I practiced:

- Variables
- Lists
- `while` loops
- `for` loops
- `if/match` logic
- Functions and methods
- User input
- `append()`
- `pop()`
- `enumerate()`
- String formatting
- Indexing
- `break`
- Type conversion with `int()`

## ✨ Features

The application supports the following commands:

### ➕ Add

Add a new todo to your list.

```text
Type add, show, edit, complete or exit: add
```
